# বাজার দর (BazarDor)

**বাজার দর (BazarDor)** is a modern, user-friendly web application designed to help people in Bangladesh stay informed about the daily prices of essential market products. It provides an easy way to explore product prices, compare price changes, and understand which products are becoming more expensive or affordable.

## Technologies Used
- **Next.js** — For building a fast, modern web application.
- **React.js** — For creating reusable and interactive UI components.
- **TypeScript** — For type safety and more reliable code.
- **Tailwind CSS** — For designing a responsive and attractive user interface.
- **REST API** — For fetching product information and market price data.

## Key Features

1. **Daily Market Price Updates:** View the latest available prices of essential products in one place.

2. **Price Increase and Decrease Tracking:** Easily identify products whose prices have increased or decreased compared to previous prices.

3. **Category-Based Product Browsing:** Find products quickly by exploring different market categories.

4. **Responsive and User-Friendly Interface:** Access market information conveniently across desktop, tablet, and mobile devices.

5. **Centralized Product Information:** Explore product names, current prices, measurement units, and percentage changes to make informed shopping decisions.
